# 评审与自检清单

用于代码评审与交付前自检。勾选前必须有证据，不接受口头声明。

## 流程门禁

- [ ] 已关联 OpenSpec change，且规划经用户确认
- [ ] 本次修改对应 `tasks.md` 中的明确任务
- [ ] 需求编号已确认，未确认项未进入实现
- [ ] 行为任务已提供 RED 运行证据
- [ ] 实现后 GREEN 运行通过，无回归
- [ ] 测试结果与未执行项已如实报告
- [ ] 存量项目已核对 `openspec/project-profile.md`，技术栈与组件选择已记录

## 存量项目

- [ ] 画像中的版本、模块与既有约定与现状一致
- [ ] 复用了现有响应、异常、错误码、基类、转换器与测试设施，无平行实现
- [ ] 影响分析覆盖模块、接口契约、表、配置、缓存、消息与测试范围
- [ ] 老代码有特征测试且 BASELINE/REGRESSION 全绿，新行为有 RED/GREEN
- [ ] 版本适配正确：`javax`/`jakarta`、Boot 2/3、JUnit 4/5、Swagger 2/3、ORM
- [ ] 只改当前范围，范围外登记技术债；契约兼容，组件变更已批准

## 命名

- [ ] 类、方法、变量、常量、包名符合规约
- [ ] 无拼音与无意义缩写
- [ ] 布尔字段未使用 `is` 前缀
- [ ] DO / DTO / VO / BO 使用正确，未用 DO 作为接口出入参

## 常量

- [ ] 无未解释的魔法值
- [ ] 状态、类型、错误码使用枚举或集中常量

## 并发

- [ ] 未使用 `Executors` 创建线程池
- [ ] 线程池显式配置核心数、最大数、有界队列、线程命名与拒绝策略
- [ ] `ThreadLocal` 在 `finally` 中清理
- [ ] `SimpleDateFormat` 未作为共享静态变量
- [ ] 锁内无远程调用与长耗时操作

## 异常

- [ ] 无空 catch，无吞异常
- [ ] 业务异常携带错误码
- [ ] 未知异常记录完整堆栈，不向前端泄漏细节
- [ ] 事务方法声明 `rollbackFor = Exception.class`

## 日志

- [ ] 使用 SLF4J 占位符，无字符串拼接
- [ ] 异常日志保留异常对象
- [ ] 无密码、令牌、身份证、手机号等敏感信息
- [ ] 关键日志包含 traceId 与业务键

## 测试

- [ ] 行为代码先写测试后实现
- [ ] 单元测试外部依赖已替身化，时间通过 `Clock` 注入
- [ ] 改动的 DAO / API 有对应集成测试
- [ ] 测试数据可重复，用例互不影响
- [ ] 覆盖率达标，核心分支全覆盖
- [ ] 测试任务与实现同组，未集中补测

## SQL

- [ ] 无 `select *`
- [ ] 无循环内单条写库，批量写入已分批
- [ ] 无大事务
- [ ] 模糊查询未以 `%` 开头
- [ ] 索引列无函数与隐式转换
- [ ] 更新语句条件明确，必要时使用乐观锁

## 分层

- [ ] Controller 薄层，无业务规则与事务注解
- [ ] 事务边界位于 Service 实现
- [ ] 数据访问收敛在 Mapper / Repository
- [ ] 无模块循环依赖

## 分布式设计

- [ ] 服务边界清晰，无共享库表
- [ ] 每个远程调用有超时
- [ ] 重试仅用于幂等操作
- [ ] 写接口与消费者有幂等策略
- [ ] 分布式事务选型有理由与补偿
- [ ] 锁粒度、租约与释放安全
- [ ] 消息键、重试与死信明确
- [ ] traceId 与关键指标可观测
- [ ] 灰度、限流、降级与优雅停机具备

## 交付

- [ ] `mvn verify` 通过
- [ ] 变更说明与影响范围已更新
- [ ] 未修改与任务无关的代码
- [ ] 遗留项已列出，并说明所需信息
